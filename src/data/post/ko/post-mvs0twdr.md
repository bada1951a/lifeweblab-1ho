## 1. 다통화 거래와 카드 결제 문제를 나누어 점검하기

해외 고객의 카드 결제가 거절되고 다통화 정산표에도 차액이 생긴 상황을 가정해 보겠습니다. 두 문제가 같은 날 발견됐더라도 원인이 같다고 단정해서는 안 됩니다. 카드 승인 실패는 결제 시도의 로그로, 환산 차액은 원거래와 실제 정산 기록으로 각각 확인해야 합니다. 이 글은 실제 수행한 고객 사례가 아닌 점검 예시입니다.

<strong>원거래 통화·금액, 결제 ID, 정산 통화·금액, 적용 환율과 수수료</strong>를 나란히 기록하면 두 문제를 구분하기 쉽습니다. 신고용 환율이나 회계 계정은 거래 성격과 적용 기준을 확인한 뒤 판단해야 하며, 차액을 임의의 계정에 넣는 것으로 세무 문제가 해결되지는 않습니다.

## 2. 카드사 거절·위험 규칙·API 오류 구분

Stripe의 결제 실패에는 카드 발급사의 승인 거절, Radar의 차단, 잘못된 API 요청 등이 있습니다. 복잡한 <strong>위험 관리 규칙(Risk Rules)</strong>과 거래 평가가 차단에 관여할 수 있지만, 장부 환산 차액 자체가 자금세탁 판정이나 특정 오류 코드를 발생시킨다는 근거는 없습니다.

로그에 표시된 실제 코드를 기록하세요. 예를 들어 `authentication_required`는 추가 인증이 필요한 경우이며, `fraudulent`는 Stripe가 사기를 의심해 거절한 경우입니다. `generic_decline`만으로 상세 원인을 확정할 수는 없습니다. 고객에게는 민감한 사기 탐지 정보를 그대로 전달하지 말고 적절한 일반 거절 안내를 제공하세요.

## 3. 거래 기록을 보존하는 점검 순서

1. <strong>결제 상세 확인:</strong> Dashboard에서 해당 시도의 결제 ID, 상태, 오류 코드와 시각을 기록합니다. 새 결제를 만들기 전에 이미 성공한 거래가 있는지도 확인합니다.
2. <strong>원인에 맞는 조치:</strong> 추가 인증이 필요하면 지원되는 결제 화면으로 고객이 인증하도록 안내합니다. 카드사 거절은 고객의 카드사 문의나 적합한 다른 결제 수단이 필요할 수 있습니다.
3. <strong>규칙 검토:</strong> 정당한 거래인지 증빙으로 판단합니다. allowlist 등록은 이미 실패한 거래를 자동 재시도하지 않으며, 이후 일치하는 시도의 차단 규칙을 우선하므로 영향을 검토해야 합니다. 보안 규칙을 일괄 완화하지 마세요.
4. <strong>대사:</strong> 원거래, 환불, 정산, 수수료와 은행 입금을 같은 거래 ID로 연결합니다. 환율 기준일·반올림·정산 시차를 따로 확인하고 설명되지 않는 차액은 원인을 기록해 검토합니다.

## 4. 재발 방지를 위한 기록 관리

결제 거절 목록과 회계 대사 목록을 분리해 담당자와 처리 상태를 남기세요. 반복 재시도보다 원인 확인이 먼저입니다. 고객의 카드번호나 인증 정보는 이메일로 수집하지 말고 결제 서비스의 안전한 화면을 이용합니다.

정산 차액과 세무 처리에 판단이 필요하면 원본 명세서를 갖추어 회계·세무 담당자와 검토하세요. 특정 환율이나 세무 양식을 모든 국가·법인에 동일하게 적용할 수는 없습니다.

## 5. 자주 묻는 질문 (FAQ)

<strong>질문 1:</strong> 환산 차액과 결제 거절이 함께 발생하면 무엇부터 확인하나요?

<strong>답변 1:</strong> 결제 시도의 상태와 정산표를 분리해 확인합니다. 결제 ID를 기준으로 원거래, 수수료, 환불, 정산과 실제 입금을 연결하고 각 차액의 원인을 기록하세요.

<strong>질문 2:</strong> allowlist에 넣으면 실패한 결제가 승인되나요?

<strong>답변 2:</strong> 기존 실패가 자동으로 재처리되지는 않습니다. 이후 시도에 영향을 주는 설정이므로 정당성·보안 영향을 확인하고, 카드사 승인과 필요한 인증도 별도로 충족해야 합니다.

<strong>질문 3:</strong> 세금 신고 전에 차액을 한 계정으로 정리하면 되나요?

<strong>답변 3:</strong> 일괄 처리로 해결된다고 단정할 수 없습니다. 적용 회계 기준과 거래 사실에 맞게 분류하고, 설명되지 않는 금액은 자료를 보존해 전문 검토를 받으세요.
